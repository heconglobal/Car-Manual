# Remaining 3D model and repair-manual work

Priority: headlights first, then the rest of the original 1985 Fiero SE 2M6, manual transmission, WS6. These are development tasks, not a diagnosis of work needed on the actual car. This records all currently identified gaps; it is not a completed factory bill of materials.

The accepted exterior and US left-hand-drive frame remain the baseline. Native interactive geometry and factory-new finishes are required throughout. Existing models still need dimensional verification where noted.
